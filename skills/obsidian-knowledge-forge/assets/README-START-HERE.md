# Start here: {{VAULT_NAME}}

This folder is a standard Obsidian Vault. No community plugin is required.

1. Extract the ZIP first. Do not try to open the ZIP itself in Obsidian.
2. In Obsidian, choose **Open folder as vault**.
3. Select the extracted `{{VAULT_NAME}}` folder.
4. Open the project home or hub note under `00-Home` or `00-首頁`.
5. Use Graph view to explore the linked knowledge.

On iPhone or iPad, move this extracted folder into `On My iPhone/Obsidian` or `iCloud Drive/Obsidian` before opening it as a Vault.

## If you received multiple Part ZIP volumes

Keep every Part ZIP and extract Part00, Part01, Part02, and later parts into the same parent location. Each archive must contain the same `{{VAULT_NAME}}` folder. Merge that folder; do not open each Part as a separate Vault. The three built-in guide files are identical in every volume and may be kept or replaced. For any other collision, stop and read `分卷ZIP安裝與合併說明.md`.

Keep `FORGE-CHECKPOINT.md` separately. It is the compact progress record used to continue the forge in a fresh ChatGPT conversation; it is not a substitute for the Vault notes.
