# OpenAI submission checklist

## Prepared

- [x] Skills-only plugin package
- [x] Final skill bundle and manifest
- [x] Production brand logo
- [x] English-first bilingual listing
- [x] Website, support, privacy, and terms URLs
- [x] Starter prompts
- [x] Five positive and three negative reviewer test cases
- [x] Country availability recommendation
- [x] Release notes
- [x] Local validation and GitHub repository

## Publisher actions required in the OpenAI Platform

- [ ] Select the OpenAI organization that will own the plugin.
- [ ] Confirm Apps Management permission is set to Write for the submitter.
- [ ] Complete or select the verified business identity for Embodied Worker Co., Ltd.
- [ ] Open the plugin submission portal and choose **Skills only**.
- [ ] Upload the final skill/plugin bundle and copy the prepared listing fields.
- [ ] Select supported countries and regions.
- [ ] Review the generated preview and run all eight test cases.
- [ ] Personally confirm the policy attestations.
- [ ] Select **Submit for Review**.

Submission starts OpenAI review; it does not immediately publish the plugin. After approval, the publisher chooses when to publish it.
