# Privacy Policy / 隱私權政策

Effective date: 2026-09-04

## English

EW Embodied Knowledge Forge is a skills-only ChatGPT/Codex plugin and a companion Obsidian importer published by Embodied Worker Co., Ltd.

- The public ChatGPT plugin does not operate an external server and does not require an API key or developer account.
- The developer does not receive, store, sell, or use the user's conversations, files, generated notes, Vault contents, or package metadata.
- Conversation and file processing occurs within the ChatGPT product selected by the user and remains subject to OpenAI's applicable terms and privacy controls.
- The Obsidian importer makes no network requests. It reads only the `.ewforge` file selected by the user and writes only inside the configured knowledge root in that Vault.
- The Obsidian importer contains no analytics, advertising, or telemetry.
- Users control their exported packages and imported Vault files and may delete them at any time through the products where they are stored.

Privacy questions: pohsun@embodiedworker.com

## 中文

具象知識鍛造器是由具象職人股份有限公司提供的 ChatGPT／Codex 技能外掛及 Obsidian 匯入工具。

- 公開版 ChatGPT 外掛不經營外部伺服器，也不要求 API 金鑰或開發者帳號。
- 開發者不會接收、保存、出售或利用使用者的聊天、檔案、生成筆記、Vault 內容或知識包資訊。
- 聊天與檔案處理由使用者選擇的 ChatGPT 產品執行，並適用 OpenAI 的相關條款與隱私控制。
- Obsidian 匯入器不會連網；只讀取使用者主動選擇的 `.ewforge`，並只寫入該 Vault 內設定的知識根目錄。
- Obsidian 匯入器不含分析、廣告或遙測。
- 使用者自行控制匯出的知識包與匯入的 Vault 檔案，可隨時透過相應產品刪除。

隱私問題請聯絡：pohsun@embodiedworker.com
